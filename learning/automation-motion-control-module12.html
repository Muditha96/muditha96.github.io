01 — Quick Understanding
PR MODE
99
Internal positioning paths (PR 1–99) stored in servo drive. Each path executes via register P5.007 or DI.CTRG trigger. Command updated every 1 ms.
E-CAM RESOLUTION
721
Maximum data points per cam curve (0.5° resolution at 720 equal divisions). Array holds up to 800 total points — multiple curves can share one array.
E-GEAR RATIO
P5.083/084
Master axis electronic gear: P5.083 = denominator, P5.084 = numerator. Higher ratio → finer phase resolution per pulse.
CYCLE TIME
1 ms
PR queue updates every 1 ms. Overlapping, sequential, and interrupt PR commands all processed through same motion command generator pipeline.

03 — Cam Profile Types & Creation Methods
E-CAM CURVE — MASTER (phase °) vs SLAVE (PUU position)
ASDA-SOFT E-CAM EDITOR — 7 CREATION METHODS (ASDA-A3 UM p.7-93)
① Manual
User enters each point position in PUU per segment. Software draws cam + speed + acceleration curve. Requires careful speed continuity to avoid vibration.
② Speed Fitting
Define target speed profile; software fits the cam curve to achieve it. Good for conveyor speed-matching applications.
③ Rotary Shear — No Sync Zone
Pointed cutter only. Inputs: gear ratio, cutter count, cutter diameter. Fastest setup, no synchronous dwell zone.
④ Rotary Shear — Fixed Sync Zone
Synchronous speed zone defined as fixed percentage of the cycle. Cutter and material run at identical speed during cutting.
⑤ Rotary Shear — Adjustable Sync Zone
Sync zone width adjustable online for variable cutting lengths. Most flexible for multi-format packaging machines.
⑥ Cubic Curve
Point-to-point mapping. Software smoothly interpolates through waypoints using cubic spline. Good for label printing and cam-follower mechanisms.
⑦ Rotary Shear — Printing Machine
Specialised mode for triple-axis synchronous printing. Three slave axes share one E-Cam curve from a single material-feeder master. Phase alignment via command overlapping: forward incremental for positive shift, reverse for negative. (ASDA-A3 UM Fig. 7.3.5.2)

CLUTCH DISENGAGEMENT MODES (P5.088.U)
U=0
DI Off → Immediate Stop
Slave stops and E-Cam disables when DI.CAM turns off. Fastest emergency stop.
U=2
DI Off → Decel Stop
Slave decelerates to stop on DI.CAM off. Protects mechanism from abrupt halt.
U=4
Pulse Count → Cyclic
Disengages when master reaches P5.089. Re-engages after P5.092 pre-engage pulse — continuous cyclic operation.
U=6
Pulse Count → Decel Stop
Disengages at P5.089 count, slave decelerates gracefully. Used in single-shot cut operations.
U=E (hex)
Pulse Count → Disable
At P5.089, slave decelerates to stop AND E-Cam function is fully disabled. Requires re-enable to restart.
U=F (hex)
DI Off OR Count → Disable
Either DI.CAM off or P5.089 count triggers decel stop and full E-Cam disable. Dual safety condition.
06 — Engineering Tips
1
Set E-Gear before creating the cam table
The master axis E-Gear ratio (P5.083 / P5.084) defines how many input pulses equal one full 360° cam cycle. Set P5.084 = encoder PPR × gear ratio before entering the ASDA-Soft E-CAM Editor — changing it afterward invalidates all phase angles in the table.
2
Check speed continuity at cam segment boundaries
When using Manual method, the software plots slave speed and acceleration curves. Verify zero discontinuities at 0° and 360°. A velocity step at the cycle boundary causes a mechanical jolt every revolution — often diagnosed as a 1× vibration at cam frequency.
3
Use Pre-engage (P5.087) to synchronise phase before engagement
Setting a lead-pulse count in P5.087 puts the system in Pre-engage state, allowing the slave to align to the correct phase offset before the clutch actually engages. For rotary shear, set this to position the cutter at maximum distance from the web before the cut zone.
4
Pulse bypass for multi-axis fan-out
Enable the Pulse Bypass function when chaining multiple slave axes to the same master. Each servo drive receives and re-amplifies the master pulse (4.5 V → 5 V), preventing attenuation across long chains. Always use twisted-pair shielded wire — each drive adds propagation delay (≈ 50 ns), which accumulates over multiple axes.
5
Scale without re-creating the cam table
P5.085 (E-Cam scaling) and P5.019 (slave axis scaling) can be modified online without stopping the machine. Use these to adjust cutting length dynamically in a packaging line — no cam re-download needed. Verify the scaled stroke does not exceed motor physical travel.
6
Monitor P5.088.D before triggering motion
Always read P5.088.D in the PLC to confirm the E-Cam is in Engage (D=1) before issuing production commands. Attempting to run with D=0 (Stop) means the slave moves on its own PR path, not the cam — a common cause of phase drift discovered only at speed.
7
PR mode timing: commands execute every 1 ms
In XDXL PLC positioning control, absolute positioning uses DRVA and relative positioning uses DRVI — both are edge-triggered. During pulse output the flag bit SM1000 stays ON; any re-trigger of the same Y output port is ignored until the current pulse sequence finishes. Design ladder logic with interlock on SM1000 to prevent double-trigger faults.
07 — Common Failures
⚙️Cam Phase Drift
Slave slowly drifts out of sync over many cycles. Cause: P5.084 (E-Gear numerator) not matched to actual encoder PPR. Fix: Recalculate P5.084 = encoder resolution × gear ratio. Verify with monitoring variable 059 (master pulse count).
🔌Clutch Refuses to Engage
E-Cam stays in Stop state (P5.088.D = 0). Cause: Engagement condition in P5.088.Z not met, or DI.CAM (DI: 0x36) not configured and active. Fix: Confirm DI.CAM is mapped and ON; verify P5.088.Z = 1 for DI-triggered engagement.
📈Speed Spike at Cycle Boundary
Motor jolts once per cam revolution. Cause: Velocity discontinuity at 0°/360° in manually entered cam table. Fix: Open ASDA-Soft speed curve view; ensure start and end velocities match. Reduce segment count near boundary and let cubic interpolation smooth the transition.
✂️Cut Length Inconsistency
Rotary shear cut lengths vary ±2–5 mm. Cause: Synchronous speed zone too narrow for cutter width — material over-stretches. Fix: Switch to Rotary Shear Fixed Sync Zone method; increase sync zone percentage to cover full cutter arc length (ASDA-A3 UM p.7-105).
📡Pulse Attenuation in Daisy Chain
Last slave in a multi-axis chain loses sync. Cause: Pulse voltage drops below threshold due to cable resistance — no pulse bypass enabled. Fix: Enable Pulse Bypass on each intermediate servo; use shielded twisted-pair with ≤ 20 Ω/km per ASDA-A3 UM recommendations.
🔄Double-Trigger in XDXL Ladder
Axis moves twice or to wrong position. Cause: DRVA/DRVI re-triggered while SM1000 (pulse sending flag) is still ON. Fix: Add SM1000 NO contact as condition before DRVA/DRVI coil. Never trigger positioning instruction while same port is outputting pulses (XDXL Manual Section 1-4-6).
🏁Phase Alignment Fails in Printing
3-axis print machine shows registration error between slaves. Cause: E-Cam phases of three slaves are offset. Fix: Use command overlapping: forward incremental command shifts phase forward, reverse shifts back. Monitor actual vs desired phase with monitoring variable 059 (ASDA-A3 UM p.7-101).
⛔AL040 — Full-Closed Loop Error
Alarm AL040 on ASDA-A3. Cause: Excessive position error between motor encoder and external encoder in full-closed loop mode. Fix: Check P1.073 (deviation limit) — may be too tight. Verify encoder cable seating and mechanical coupling. Confirm P1.072 integer constraint (ASDA-A3 UM p.6-56).
08 — Pro Engineer Notes
⭐ Rotary Shear Speed Equation
Synchronous speed zone proportion = cutter width arc / total circumference. If cutter diameter = 150 mm and cutting length = 500 mm, sync zone ≈ 150π/500 = 94% — leaves almost no room for acceleration. Use a smaller cutter or add cutter count to relieve the speed demand on the motor.
⭐ Data Array Capacity Planning
The full 800-point array can store multiple E-Cam curves with different start addresses set via P5.081. In a machine with format changeover, pre-load all format cam tables into the array at startup and switch between them by simply changing P5.081 — zero download time during production run.
⭐ XDXL Pulse Unit Selection
XD/XL PLC SFD900 register bit 8–10 selects pulse unit: 000=pulse count, 001=micron, 011=centimillimeter, 101=decimillimeter, 111=millimeter. Setting the unit to physical distance (µm or mm) moves the scaling into the PLC, keeping servo parameters clean and simplifying HMI input validation.
⭐ Clutch Mode Selection Rule
For continuous production (winding, printing): use U=4 cyclic mode — automatic re-engagement via P5.092 pre-engage pulse. For single-shot operations (punching, labelling): use U=6 (decel stop at count). For safety-critical stops: map both DI.CAM and count condition with U=F to guarantee disengage by either trigger.
