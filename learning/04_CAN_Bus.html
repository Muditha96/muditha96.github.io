🚗CAN Bus

The protocol that runs every modern vehicle and mobile machine.

Quick Definition

CAN Bus (Controller Area Network) is a multi-master serial protocol where any device can broadcast messages on a shared 2-wire bus — robust enough to survive electrical noise on vehicles and machines.

Key Facts
  • ✓ 2-wire differential bus — extremely noise-resistant
  • ✓ Multi-master — any node can broadcast
  • ✓ Priority via message ID (no master needed)
  • ✓ Up to 1 Mbps (Classic) / 8 Mbps (CAN-FD)
  • ✓ 120Ω termination at both ends — critical!
Real Industrial Example
🚜

A forklift or harvester uses CAN Bus (often CANopen or J1939) to link engine, hydraulics, joystick, and display — replacing dozens of dedicated wires with just two.

Quick Check

Q: Why doesn't CAN Bus need a master device like Modbus does?

Tap to reveal answer ↓ A: CAN uses message-based arbitration — each message has an ID and the lowest ID automatically wins the bus. No coordinator needed; the protocol itself decides who talks next.
