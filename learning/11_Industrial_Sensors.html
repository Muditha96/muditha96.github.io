👁️Industrial Sensors

The eyes and ears of every automated machine.

Quick Definition

Industrial sensors are non-contact detection devices that tell the PLC what's happening on the line — presence, position, level, distance — without moving parts to wear out.

Inductive Sensor

Generates an electromagnetic field. When a metal object enters the field, eddy currents change the oscillator amplitude and switch the output ON.

Detects: Metals only · Range: 1–60 mm · Speed: very fast
Key Facts
  • ✓ Non-contact = no mechanical wear, long life
  • ✓ Standard outputs: PNP / NPN, NO / NC
  • ✓ M8, M12, M18, M30 are common cylindrical sizes
  • ✓ IP67 / IP69K — washdown & dust proof
  • ✓ Smart versions speak IO-Link (see Lesson 05)
Real Industrial Example
🏭

A conveyor sorting line uses 3 sensor types together: inductive for metal cans, capacitive for plastic bottles, and photoelectric for cardboard boxes — sorting them into 3 lanes automatically.

Quick Check

Q: Which sensor type would you choose to detect water level inside an opaque plastic tank?

Tap to reveal answer ↓ A: A capacitive sensor mounted on the tank wall. It detects the change in dielectric constant when liquid is present behind the plastic — without contacting the liquid.
Memory Hook

"Metal → Inductive. Anything → Capacitive. Far away → Photoelectric."
