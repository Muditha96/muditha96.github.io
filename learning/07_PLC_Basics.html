🧠PLC Basics

The brain that runs every modern factory.

Quick Definition

A PLC (Programmable Logic Controller) is an industrial computer that reads inputs, runs logic, and switches outputs — repeating thousands of times per second to control machines.

How It Works — The Scan Cycle
📥1. Read Inputs
⚙️2. Run Logic
📤3. Write Outputs
🩺4. Diagnostics
🔄 Repeat
every 1–10 ms
Simplest Program — Ladder Logic
[Start] [/Stop] (Motor)
[Motor] (Lamp)

Press Start (and Stop not pressed) → Motor runs → Lamp ON.

Key Facts
  • ✓ Designed for harsh environments — heat, vibration, dust
  • ✓ Scan cycle typically 1–10 ms — deterministic, real-time
  • ✓ Programs use IEC 61131-3 languages (Ladder, FBD, ST, SFC)
  • ✓ Modular: CPU + I/O cards + comm modules
  • ✓ Top brands: Siemens, Allen-Bradley, Mitsubishi, Omron
Real Industrial Example
🏭

A bottle-filling line uses one PLC to read sensors (bottle present, level OK), run the recipe logic, and command valves, pumps, and the conveyor — 24/7, with millisecond precision.

Quick Check

Q: Why use a PLC instead of a regular PC for machine control?

Tap to reveal answer ↓ A: PLCs are deterministic (predictable scan time), rugged (no fans, sealed), and reliable for 10–20 years. PCs can stall, crash, or get viruses — unacceptable for safety and production.
