Lesson 01 · Industrial Communication

⚡Modbus RTU

The most widely used protocol in factory automation.

Quick Definition

Modbus RTU is a serial communication protocol where one master device polls multiple slave devices over RS-485 to read sensors and control machines.

How It Works
🖥️ PLC (Master)
Request →
📟 VFD / Sensor (Slave)
← Response
🖥️ PLC reads data
Key Facts
  • ✓ Master-Slave architecture (1 master, up to 247 slaves)
  • ✓ Runs on RS-485 — 2 wires, long distance (up to 1200 m)
  • ✓ Simple, open standard — no license fees
  • ✓ Slower than Ethernet (typically 9600–115200 baud)
  • ✓ Uses function codes (e.g., 03 = Read Holding Register)
Real Industrial Example
🏭

In a bottling plant, a PLC uses Modbus RTU to read motor speed from 8 VFDs on the conveyor line and adjust them in real time to match production speed.

Quick Check

Q: Why is Modbus RTU still popular in 2026 despite being from 1979?

Tap to reveal answer ↓ A: Because it is simple, reliable, royalty-free, and almost every PLC, VFD, and sensor still supports it — making it the universal "lingua franca" of industrial devices.
